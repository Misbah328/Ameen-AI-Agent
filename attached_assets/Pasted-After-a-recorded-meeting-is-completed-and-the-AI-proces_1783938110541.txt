After a recorded meeting is completed and the AI processing finishes, show the generated Tasks and Decisions on the same meeting page.

Do not redirect the user to a separate page immediately. The organizer or secretary should be able to review, edit, assign, and approve the generated items directly inside the completed meeting.

Required Post-Meeting Flow

When the user clicks End Meeting:

Stop the recording and live transcription.
Process the transcript.
Generate draft minutes.
Extract draft decisions.
Extract draft tasks/action items.
Keep the user on the same meeting page.
Show a clear processing status until the results are ready.
Automatically display the generated results when processing is complete.
Post-Meeting Results Layout

After processing, show the following sections on the same page:

Meeting Summary
Draft Minutes
Decisions
Tasks / Action Items
Unresolved Discussion Points

The user should also be able to access the same information from the existing tabs:

Minutes
Decisions
Actions

Do not create duplicate records when the user moves between tabs.

Reject it

Assignment Behaviour

When the user assigns and approves a task:

Save it as an official meeting action.
Add it to the meeting’s Actions tab.
Add it to the central Tasks section of the platform.
Link it permanently to the originating meeting.
Link it to the relevant entity.
Link it to the related agenda item or decision, where applicable.
Show the meeting title and meeting date in the central task record.
Notify the assigned person according to the existing notification rules.

Example:

Task: Prepare the revised financial report
Assigned to: Sarah Ahmed
Due date: 20 July 2026
Origin: Executive Meeting — Performance Review
Related agenda item: Financial Performance Review

The task must appear both:

Inside the meeting under Actions
In the main platform Tasks section

Both views must reference the same database record. Do not create two separate copies.

AI-generated decisions must not become official automatically.

Editing and Synchronization

When a task is updated from the central Tasks section, the change must appear in the meeting Actions tab.

The same synchronization rule applies to decisions shown in different parts of the platform.

Permissions

Only authorized users should be able to approve AI-generated tasks and decisions.

Suggested permissions:

Organizer
Meeting secretary
Governance administrator
Authorized committee chair

Regular attendees may view or comment only if permitted.

An assignee may update the status of their assigned task but should not change the original meeting decision unless authorized.
