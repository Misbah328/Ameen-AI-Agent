Please improve the existing Live Meeting page shown in the attached screenshot. Do not redesign the entire Meetings module. Focus only on the live meeting, recording, transcription, and end-meeting experience described below.

Main Objective

When a scheduled meeting is started, the system should guide the user through a proper live meeting workflow:

Start the meeting.
Ask whether recording should begin.
Show live transcription while the meeting is in progress.
Allow the meeting organizer to review live participants, agenda, notes, decisions, and actions.
End the meeting clearly and safely.
After the meeting ends, process the transcript and generate draft minutes, decisions, and action items.
Phase 1 — Start Meeting and Recording Confirmation

When the organizer clicks Start Meeting, show a confirmation modal before entering the live session.

Modal content

Title: Start Live Meeting

Message:
Would you like to start recording and live transcription for this meeting?

Options
Start Meeting with Recording
Start Meeting without Recording
Cancel
Behaviour

If the user selects Start Meeting with Recording:

Start the live meeting.
Start the recording.
Start live transcription.
Store the actual meeting start time.
Show a visible “Recording” status.
Show a visible “Live Transcript” status.

If the user selects Start Meeting without Recording:

Start the live meeting.
Do not record audio.
Do not generate transcription.
Still allow manual notes, actions, and decisions.
Show a clear “Not Recording” status.

Only authorized users, such as the organizer or meeting secretary, should be able to start or stop the recording.

Phase 2 — Live Transcription

Replace the current empty transcript panel with a real live transcription area.

Live transcription behaviour

While the meeting is running and recording is active:

Show transcription text as it is generated.
Add new text continuously without refreshing the page.
Auto-scroll to the latest transcript entry.
Allow the user to pause auto-scroll.
Show the speaker name when available.
Show the timestamp beside each transcript segment.
Keep previous transcript text visible.
Save transcript segments continuously to prevent data loss.
Example transcript format

13:06 — Mohammad W. Albuali
We need to complete the financial review before the next board meeting.

13:07 — Sarah Ahmed
I will prepare the updated report by Sunday.

Transcript states

Support the following states:

Connecting
Recording
Transcribing live
Paused
Processing
Completed
Failed

If transcription temporarily fails, show a retry message without ending the meeting.
