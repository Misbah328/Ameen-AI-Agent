==================================================
PROBLEM
==================================================

The Boards & Committees section may show duplicate boards.

Possible symptoms:

- Same board appears more than once
- Duplicate board is created after double-clicking Save
- Refresh creates another copy
- Same board appears with slightly different IDs
- Dashboard and Governance show different board totals
- Duplicate API results or duplicate database rows

==================================================
EXPECTED BEHAVIOR
==================================================

Each real board must appear only once.

Creating a board must create exactly one database record.

Double-clicking Save must not create duplicates.

Refreshing or reopening the page must not duplicate boards.

==================================================
INVESTIGATION
==================================================

Check:

- Board creation form
- Save button handlers
- API POST endpoint
- Database insert logic
- Event listeners
- Double-click handling
- Retry logic
- Frontend rendering
- API joins
- Cached board data
- Seed or fallback data
- Board name and organization matching

Determine whether duplicates come from:

- Duplicate database rows
- Duplicate API response rows
- Duplicate frontend rendering
- Multiple POST requests
- Fake/mock fallback boards

==================================================
FIX REQUIREMENTS
==================================================

1. Prevent duplicate submissions:
- Disable Save while the request is processing
- Ignore repeated clicks
- Re-enable Save after success or error

2. Prevent duplicate database records:
- Use a safe uniqueness rule for board name within the same organization
- Trim spaces
- Compare names case-insensitively
- Do not create another board if the same board already exists

3. Prevent duplicate rendering:
- Render each unique board ID only once
- Remove mock/fallback duplicates when real API data exists

4. Show a clear message if a duplicate board already exists.

Do not delete legitimate boards automatically.
