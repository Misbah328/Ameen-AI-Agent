==================================================
PROBLEM
==================================================

The “View Details” button in the Tasks section does not work correctly.

Possible symptoms:

- Nothing happens when clicked
- Wrong task opens
- Old task details appear
- Modal opens blank
- Button works only once
- Task details disappear after refresh
- Dashboard task links open the wrong task

==================================================
EXPECTED BEHAVIOR
==================================================

When the user clicks “View Details”:

- The exact selected task must open
- Correct Task ID must be used
- Show:
  - Task title
  - Description
  - Assignee
  - Due date
  - Priority
  - Status
  - Related meeting or resolution
  - Attachments, if available
  - Activity or audit history, if available

No stale data from another task should appear.
